# 数据库脚本说明

## 文件说明

| 文件 | 说明 |
|------|------|
| `schema.sql` | 数据库表结构 DDL（12 张业务表，含会员、堂食订单、外卖订单） |
| `generate_data.py` | 模拟数据生成与插入脚本（按天循环、每月提交） |

## 使用步骤

### 1. 建表

```bash
mysql -h localhost -u root -p catering_ai_system < schema.sql
```

### 2. 生成模拟数据

```bash
pip install pymysql
cd doc/sql
python generate_data.py

# 或通过环境变量覆盖数据库配置
DB_HOST=192.168.1.100 DB_PASSWORD=yourpass python generate_data.py
```

### 3. 自定义配置

编辑 `generate_data.py` 底部的 `CONFIG` 字典：

```python
CONFIG = {
    "DB_HOST": "localhost",
    "DB_PORT": 3306,
    "DB_USER": "root",
    "DB_PASSWORD": "liu12138",
    "DB_NAME": "catering_ai_system",
    "START_DATE": "2023-01-01",    # 全局数据起始日期
    "END_DATE": "2026-05-17",      # 数据结束日期
    "STORE_COUNT": 500,             # 门店数量
    ...
}
```

## 数据说明

### 门店分布
- **均匀覆盖**全国 31 个省级行政区（含直辖市、自治区）
- 每个省份 3-5 个城市，各城市 2-7 家门店
- 门店命名格式：`省份+城市+xxx店`（如"广东广州001店"）

### 订单数据结构
- **核心**: 每条订单记录一笔真实交易，订单数据分两张表存储
- **堂食订单表 (`dine_in_order`)**: 存储堂食订单的金额、支付方式、关联会员，区分会员订单与非会员订单
- **外卖订单表 (`takeout_order`)**: 存储外卖订单的金额、外卖平台（美团/饿了么/抖音），不含支付方式
- **订单明细表 (`order_item`)**: 记录每笔订单包含的 1~4 个菜品

#### 支付方式分布（仅堂食）
| 方式 | 占比 |
|------|:----:|
| 微信支付 | 50% |
| 支付宝支付 | 35% |
| 现金支付 | 15% |

#### 订单类型分布
| 类型 | 占比 |
|------|:----:|
| 堂食 | 60%~85% |
| 外卖 | 15%~40% |

#### 堂食会员占比
| 类型 | 占比 |
|:----:|:----:|
| 会员订单 | 50% |
| 非会员订单 | 50% |

#### 每单菜品数分布
| 菜品数 | 占比 |
|:------:|:----:|
| 1 道 | 15% |
| 2 道 | 35% |
| 3 道 | 33% |
| 4 道 | 17% |

### 生成策略

- **按天循环**: 从 2023-01-01 开始，按天逐日生成，而非逐店依次生成
- **全量门店**: 当天所有营业门店均生成数据，处理顺序随机打乱
- **每月提交**: 月份切换时提交一次数据库，大幅减少 I/O 次数
- **价格统一**: 同一门店的同一种菜品价格始终保持一致（不同门店可有 ±4% 浮动）
- **高峰时段**: 下单时间集中在午餐（11:00-13:00）和晚餐（17:00-19:00）高峰

### 营业数据
- **数据周期**: 每家门店从开业到 2026-05-17，开业时间在 2023-01-01 ~ 2025-07-02 之间随机，经营时长 10 个月 ~ 3 年 4 个月不等
- **日营业额**: 每店每日 1000~3000 元
- **客单价**: 22~38 元
- **节假日倍率**: 元旦 1.3x / 春节 1.6x / 国庆 1.5x / 周末 1.12x
- **季节效应**: 夏季（6-8 月）旺 1.12~1.15x，冬季（12-2 月）淡 0.90~0.95x
- **营业汇总 (`daily_summary`)**: 每日每店一条，由订单聚合生成

### 菜品数据
- 共 56 道中式快餐常见菜品（热菜/凉菜/主食/汤品/饮品/配菜）
- 所有门店使用同一全局菜单，订单按 popularity 权重选菜

### 会员数据（暂不生成）
- 会员数据因会员画像模块暂不实现，数据生成脚本已跳过
- 堂食订单中 `member_id` 字段均为 NULL

### 评论数据
- 覆盖约 15% 的营业日
- 评分分布偏正面（好评约 60%，中评 25%，差评 15%）
- 平台: 美团 / 饿了么 / 大众点评

### 用户账号
- 1 个管理员（老板）
- 5 个普通员工
- 每家门店 1 个加盟商账号

## 数据量估算

> 注：门店开业时间随机分布在 2023-01-01 ~ 2025-07-02 之间，数据结束日期统一为 2026-05-17。
> 估算基于平均经营时长 ~2 年计算。

| 数据项 | 数据量（约） |
|--------|-------------|
| 门店 | 500 条 |
| 菜品 | 56 条 |
| 会员 | 暂不生成 |

| **外卖订单** | **3,000,000+ 条** |
| **订单明细** | **20,000,000+ 条** |
| 营业汇总 | 160,000+ 条 |
| 评论 | 24,000+ 条 |

> 注意：订单和明细数据量较大（约 3100 万行），首次生成预计耗时 15-30 分钟，请耐心等待。
