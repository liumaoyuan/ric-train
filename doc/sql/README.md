# 数据库脚本说明

## 文件说明

| 文件 | 说明 |
|------|------|
| `schema.sql` | 数据库表结构 DDL（10 张业务表） |
| `generate_data.py` | 模拟数据生成与插入脚本 |

## 使用步骤

### 1. 建表

```bash
mysql -h localhost -u root -p for_student < schema.sql
```

### 2. 生成模拟数据

```bash
pip install pymysql
cd doc/sql
python generate_data.py

# 或通过环境变量覆盖数据库配置
DB_HOST=192.168.1.100 DB_PASSWORD=yourpass python generate_data.py
```

### 3. 自定义配置

编辑 `generate_data.py` 底部的 `CONFIG` 字典：

```python
CONFIG = {
    "DB_HOST": "localhost",
    "DB_PORT": 3306,
    "DB_USER": "root",
    "DB_PASSWORD": "liu12138",
    "DB_NAME": "for_student",
    "START_DATE": "2025-01-01",    # 数据起始日期
    "END_DATE": "2025-12-31",      # 数据结束日期
    "STORE_COUNT": 500,             # 门店数量
    ...
}
```

## 数据说明

### 门店分布
- **均匀覆盖**全国 31 个省级行政区（含直辖市、自治区）
- 每个省份 3-5 个城市，各城市 2-7 家门店
- 门店命名格式：`省份+城市+xxx店`（如"广东广州001店"）

### 订单数据结构
- **核心**: 每条订单记录一笔真实交易，区分支付方式
- **订单表 (`orders`)**: 存储每笔订单的金额、支付方式、订单类型、下单时间
- **订单明细表 (`order_item`)**: 记录每笔订单包含的 1~4 个菜品

#### 支付方式分布
| 方式 | 占比 |
|------|:----:|
| 微信支付 | 50% |
| 支付宝支付 | 35% |
| 现金支付 | 15% |

#### 订单类型分布
| 类型 | 占比 |
|------|:----:|
| 堂食 | 60% |
| 外卖 | 40% |

#### 每单菜品数分布
| 菜品数 | 占比 |
|:------:|:----:|
| 1 道 | 15% |
| 2 道 | 35% |
| 3 道 | 33% |
| 4 道 | 17% |

### 营业数据
- **数据周期**: 1 年（2025 年全年）
- **日营业额**: 每店每日 1000~3000 元
- **客单价**: 22~38 元
- **节假日倍率**: 元旦 1.3x / 春节 1.6x / 国庆 1.5x / 周末 1.12x
- **天气影响**: 暴雨/台风 0.75x / 雨雪 0.90x
- **营业汇总 (`daily_summary`)**: 每日每店一条，由订单聚合生成

### 菜品数据
- 共 31 道中式快餐常见菜品（热菜/凉菜/主食/汤品/饮品/配菜）
- 所有门店使用同一全局菜单，订单按 popularity 权重选菜

### 评论数据
- 覆盖约 15% 的营业日
- 评分分布偏正面（好评约 60%，中评 25%，差评 15%）
- 平台: 美团 / 饿了么 / 大众点评

### 用户账号
- 1 个管理员（老板）
- 5 个普通员工
- 每家门店 1 个加盟商账号
